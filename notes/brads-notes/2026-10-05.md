## The closed loop (plan item 2)

`npm run servo`: render where the robot really put the part (gap-sweep, one
pose, four views, pooled edges), solve against a saved calibration with the
last estimate + commanded move as prior, command, repeat to contact. Robot:
2% scale error per axis, 0.02 mm noise per move, start believed 1 mm off.

    npm run position -- --x ... --turn ... --max-views 4 --calibrate hinged \
        --save-calibration results/servo/stack-2g-hinged.calibration.json
    npm run servo -- --name h-a-p2 --calibration results/servo/stack-2g-hinged.calibration.json \
        --start 1.5,6,-1.2,1.5 --seed 1 --lateral-floor 2 \
        --carry-from results/stack-2g-x/pairs --carry-from ... (y, z, turn)

Seven loops: 3-5 renders each, contact within ~0.05 mm per axis. Estimates
at >= 2 mm up within 0.03 mm every frame; the end error is the robot's last
moves. At ~1 mm x reads 0.06-0.10 off in EVERY run (calibration at a 4 mm
lift used at 1: not linear); --lateral-floor 2 stops sideways correction
there and fixes it (start B x 0.07 -> 0.01). Hypotheses resolved 6/6 at 1 mm.
Joint vs hinged in the loop: x 0.11 vs 0.04.

solvePosition takes a prior (mean, covariance). `npm run position --
--sequence <dir>` solves a sweep frame by frame, alone and carried: prior =
last solution + commanded move, covariance + motion^2.

mm, single views included. Redone with the commanded poses = truth + random

line to beat (0.7/1.1/0.9 mm).
